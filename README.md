# Rise Of Sky

초대제 3D 공중전. 브라우저끼리 직접 연결(WebRTC)해서 돌아가며, **게임 서버가 없습니다.**

`index.html` 파일 하나가 전부입니다. 빌드 과정도, 설치할 것도 없습니다.

## 어떻게 같이 하나

1. 한 사람이 **Open a flight** 를 누르면 **스쿼크** 4자리가 배정됩니다.
   실제 항공기 트랜스폰더와 같은 0–7 숫자 네 자리입니다.
   (7500 · 7600 · 7700 은 진짜 비상 코드라 배정되지 않습니다.)
2. **Copy link** 로 나온 주소를 친구에게 보냅니다. 주소 끝에 스쿼크가 붙어 있어서,
   친구는 링크만 열면 자동으로 들어옵니다.
3. 초대 명단(Invite list)에 콜사인을 미리 적어두면 바로 입장하고,
   없으면 호스트가 승인해야 들어옵니다.

호스트의 브라우저가 편대 전체를 중계합니다. **호스트가 창을 닫으면 편대가 해산됩니다.**

## 연결이 안 될 때

멀티플레이 칸의 **RUN CHECK** 를 양쪽 다 눌러보세요.

| 결과 | 뜻 |
|---|---|
| `Ready` | 브로커 도달 + 공인 주소 확인. 다른 네트워크의 친구와 연결됩니다. |
| `Local only` | 엄격한 NAT 뒤에 있습니다. 같은 네트워크끼리만 될 수 있습니다. |
| `Blocked` | 방화벽·프록시가 막고 있습니다. |

`Local only` 나 `Blocked` 가 뜨면 `index.html` 안의 `const ICE = { iceServers:[...] }`
배열에 무료 TURN 중계 서버를 한 줄 추가하면 해결됩니다.
학교·회사 네트워크에서는 실제로 막힐 수 있습니다.

## 조종

좌측 **Controls** 에서 키보드와 마우스 중 고릅니다.

**키보드** — `W`/`S` 피치, `A`/`D` 롤, `Q`/`E` 러더, `Shift` 부스터,
`Space` 기관포, `F` 미사일. 속도 조절은 따로 없고 항상 순항 추력입니다.

**마우스** — 하늘을 클릭하면 포인터가 잡힙니다. 마우스가 조종간이고,
실제 조종간처럼 놓은 자리에 머뭅니다. `Z` 로 중립 복귀.
좌클릭 기관포, 우클릭 미사일, `Shift` 부스터. 감도와 피치 반전을 설정할 수 있습니다.

공통 — `T` 무전, `Tab` 순위, `C` 시점 전환, `Esc` 귀환

## 기체

격납고(**Hangar**)에 4기종이 들어 있습니다.
파일럿마다 고른 기체가 편대원 화면에도 그대로 보입니다.

직접 만든 모델도 넣을 수 있습니다.

- **끌어다 놓기** — `.glb` · `.gltf` · `.obj` 를 격납고에 놓으면 됩니다.
  이 방식은 **그 브라우저에서만** 보입니다.
- **사이트에 동봉** — 모델 파일을 `index.html` 옆에 두고 격납고의 경로 칸에
  파일 이름을 적으면, 링크로 들어온 편대원 전원이 같은 기체를 봅니다.

기수가 어느 축을 향하든 Yaw · Pitch 슬라이더로 맞추면 되고, 크기는 자동으로
정규화됩니다. 저장소의 `testdart.obj` 는 일부러 기수를 +X 로 틀어둔 시험용
모델입니다 — 보정이 어떻게 동작하는지 먼저 확인해 보세요.

### 파트별 색 · 엔진 · 프로펠러

모델의 **메시 이름**으로 파트를 알아봅니다. 3D 툴에서 파트마다 이름을 붙여 내보내세요.

| 이름에 이 단어가 들어가면 | 동작 |
|---|---|
| `engine` `nozzle` `exhaust` `thrust` `burner` | 그 파트 뒤끝에 후연이 붙습니다. 여러 개면 각각. |
| `prop` `rotor` `blade` `spinner` | 스로틀에 따라 회전합니다. 회전축은 격납고에서 고릅니다. |
| 그 외 (`fuselage` `wing_L` `canopy` …) | 격납고에서 파트마다 색을 따로 지정할 수 있습니다. |

이름이 하나도 없으면 한 덩어리로만 칠해집니다. 엔진 이름이 없으면 후연은 기체 뒤끝 가운데 하나만 붙습니다.
저장소의 `testparts.obj` 가 이 규칙대로 이름을 붙인 시험 모델입니다.

## 배포

정적 파일이라 아무 정적 호스팅에나 올리면 됩니다.
GitHub Pages 라면 저장소 **Settings → Pages → Source** 를 `main` 으로 지정하면 끝입니다.

경로 의존성이 없어서 `https://<아이디>.github.io/<리포명>/` 같은 하위 경로에서도
그대로 동작합니다.

## 기술 메모

- **three.js r128** — 지형·하늘·기체 렌더링. 지형은 값 노이즈 fBm 으로 생성합니다.
- **PeerJS 1.5.5** — WebRTC 스타 토폴로지. 호스트가 전원의 상태를 16Hz 로 재방송합니다.
- 네트워크 송신은 `requestAnimationFrame` 과 분리돼 있습니다. 브라우저는 백그라운드 탭의
  rAF 를 완전히 멈추기 때문에, 호스트가 탭을 옮겨도 중계가 죽지 않도록 `setInterval` 로
  돌립니다.
- 파일럿 기록(콜사인 · 크레딧 · 부품)은 `localStorage` 에, 반입한 모델은 `IndexedDB` 에
  저장됩니다. 브라우저마다 별개입니다.
- 거래는 서버 검증 없이 양쪽 브라우저가 각자 반영합니다. 친구들끼리 신뢰하는 전제입니다.
